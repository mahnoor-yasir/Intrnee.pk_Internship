The project goes beyond a basic file input by implementing drag-and-drop functionality, image previews, file validation, upload progress simulation, persistent browser storage, and image management features.

### Core Features

- Drag-and-drop file uploading
- Browser file selection
- Multiple image selection
- Image preview
- JPG support
- JPEG support
- PNG support
- GIF support
- File type validation
- File size validation
- Error handling
- Simulated upload progress
- Upload status indicators
- Image gallery
- Image search
- Image filtering
- Image sorting
- Grid and list views
- Image lightbox preview
- Image download
- Image rename
- Individual image deletion
- Clear-all functionality
- Duplicate handling
- Persistent browser storage
- Responsive interface
- Light/dark theme support
- Toast notifications

### Browser APIs Used

The project demonstrates practical use of:

- File API
- FileReader API
- Drag-and-Drop API
- localStorage API
- DOM API
- Browser download functionality

### Upload Flow

The application follows a structured upload process:

**Select / Drop File**

↓

**Validate File**

↓

**Generate Image Preview**

↓

**Add to Upload Queue**

↓

**Simulate Upload Progress**

↓

**Mark Upload as Complete**

↓

↓

**Display Image in Library**

### Storage

Uploaded image data is persisted using browser storage so that the image library can remain available after a page refresh.

The application also provides storage usage information and handles storage-related errors gracefully.
